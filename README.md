# جمعه — فرهاد مهراد

یک صفحهٔ تک‌صفحه‌ای (SPA تکی، بدون build) برای ترانهٔ **«جمعه»**؛ شعر **شهیار قنبری**،
آهنگ **اسفندیار منفردزاده** و صدای **فرهاد مهراد** — ۱۳۵۰.

بدون هیچ کتابخانه یا CDN؛ فونت‌ها و تصاویر همه داخل پروژه‌اند.

---

## اجرا

```bash
npm start        # http://localhost:5173
```

یا با هر سرور ایستای دیگر؛ کافی است پوشهٔ پروژه سرو شود:

```bash
python3 -m http.server 5173
```

> برای بازکردن مستقیم `index.html` هم صفحه نمایش داده می‌شود، ولی پخش آهنگ و
> تشخیص خودکار فایل فقط روی `http://` کار می‌کند (محدودیت مرورگرها با `file://`).

---

## آهنگ

فایل صوتی به دلیل **حق نشر** همراه این مخزن نیست. برای پخش دائمی:

```
assets/audio/jomeh.mp3
```

اگر مسیر یا نام دیگری داری، در `assets/js/app.js` مقدار `SRC` را عوض کن.

بدون فایل هم صفحه از کار نمی‌افتد: با زدن دکمهٔ پخش، پنجرهٔ انتخاب فایل باز می‌شود،
یا می‌توانی فایل MP3 را روی کادر پخش‌کننده رها کنی. فایل هیچ‌جا آپلود نمی‌شود و
فقط در مرورگر خودِ کاربر پخش می‌شود.

---

## امکانات

- پخش‌کنندهٔ کامل: پخش/توقف، نوار پیشرفت با کشیدن، بازهٔ بافر، صدا و بی‌صدا (ذخیره در `localStorage`)
- صفحهٔ گرامافون که هنگام پخش می‌چرخد و میله‌های صدا با Web Audio API دور آن می‌رقصند
- رهاکردن فایل صوتی روی پخش‌کننده (Drag & Drop) و انتخاب فایل از دستگاه
- متن کامل ترانه با ظهور تدریجی هر بند هنگام اسکرول
- چیدمان راست‌به‌چپ و واکنش‌گرا (موبایل، تبلت، دسکتاپ)
- احترام به `prefers-reduced-motion`، ناوبری با کیبورد (`Space`، `←`/`→`، `Home`/`End`)
- فونت‌های Lalezar و Vazirmatn (نسخهٔ woff2، میزبانی محلی)

## ساختار

```
index.html
server.js                 سرور ایستای بدون وابستگی (با پشتیبانی Range برای آهنگ)
assets/
  css/style.css
  js/app.js
  fonts/                  Lalezar + Vazirmatn (woff2)
  img/                    cover.jpg ، record.jpg  (تولیدشده با هوش مصنوعی)
  audio/                  جای فایل آهنگ — به دلیل حق نشر خالی است
```

## نکتهٔ حقوقی

«جمعه» اثری دارای حق نشر است. این صفحه فقط برای استفادهٔ شخصی/آموزشی است و
فایل صوتی را نه میزبانی می‌کند و نه توزیع. اگر این صفحه را عمومی منتشر می‌کنی،
اجازهٔ پخش آهنگ را از صاحبان حق (خواننده/آهنگساز/ناشر) بگیر.
متن ترانه از منابع عمومی (ویکی‌پدیای فارسی) نقل شده است.
